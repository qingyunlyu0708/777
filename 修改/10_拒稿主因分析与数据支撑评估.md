## 一、对作者四点自我诊断的判定与排序

### 1.1 「理论贡献没有被做出来」——确认，这是第一位的拒稿原因

您的判断准确，且可以更进一步：问题不是贡献「写得不够清楚」，而是全文没有指认
**一条被本研究改变的既有理论命题**。目前的写法是「用理论描述现象」：S-D logic 提供
词汇（资源整合），co-destruction 提供对照（负面价值），community participation 提供
角色谱系，voice–exit 提供退出前的行为框架——四套理论各自完好无损地进场、完好无损地
离场。审稿人读完知道「发生了什么」，但不知道「哪条既有命题因此要改写」。

**可指认的目标命题其实已经在数据里**：参与/共创文献的累积性假设——
「参与越深、资源整合越充分，价值越增值，用户越向社区中心移动」。
您的数据显示的反命题是：**深度参与同时建构了价值与脆弱性——投入最深的用户因其投入
最深，在条件失守时转化为最具破坏力的批评者；产生价值的机制与产生衰减的机制是同一个
（资源投入结构），而非两个并列现象**。这才是「改变命题」级别的贡献表述：
不是「共创也会衰减」（现象描述），而是「衰减内生于共创自身的资源投入结构」（机制主张）。

全文的贡献表述应收敛到这一条主线；其余（沉浸式情境扩展、角色架构）降为从属贡献或
主贡献的支撑面，不再并列为「三大贡献」。三个半成品贡献不如一个做完整的贡献。

**关于 co-creation attenuation 的定位（构念 vs sensitising concept）——建议：
明确定位为过程性概念 / sensitising concept，不要主张完整新构念。** 理由：

1. **数据承载力**：新构念的论证负担是概念区分效度 + 法则网络（nomological network）
   + 可操作化前景。10 次访谈 + 单平台 90 小时网志撑不起这套论证，审稿人会用
   construct 的标准来审并击穿它。
2. **方法论一致性**：溯因/定性设计的产出本来就是 mid-range 过程概念，主张
   sensitising concept（Blumer 意义上的「指引注意的概念」）与设计自洽，且把审稿
   标准从「构念效度」降到「解释增量」。
3. **解释增量必须明说**：attenuation 相对既有概念的不可替代性只有一条——
   **内生性**。co-destruction 捕捉离散负面事件，disengagement/fatigue 捕捉个体
   状态，platform decay 捕捉系统终态；它们的并集仍不能解释「衰减为何恰恰经由
   最投入的用户、经由角色间依赖结构传导」。这一句话必须出现在 2.4 和讨论中，
   现在没有。
4. **必须删除的自相矛盾**（现稿硬伤，见第三节）：2.4 说 attenuation 与
   co-destruction「三点不同」（是另一种过程），讨论 5.2 却说它是 co-destruction
   的 "antecedent / softer precursor"（是同一过程的早期阶段）。二者只能取一：
   若是 antecedent，审稿人一句「那就是早期 co-destruction，何来新概念」即可否掉。
   建议保留「不同类过程」（chronic vs acute）的定位，**删掉 antecedent 句**。

### 1.2 「资源说得过宽」——确认，第二位原因，且有零成本的收敛方案

resources / resource provision / role-specific resources / availability /
accessibility / direction / continuity / conditions 这组术语的问题不是「多」，
而是**没有分析关系**：它们既非层级（谁包含谁），亦非序列（谁先于谁），审稿人
无法用它们做任何推理。

**收敛方案（纯删除，不新增概念）**：全文只保留一组二元区分——

- **用户投入的资源**（resources users invest）：每个角色一种主导资源，发现章节
  已经写出——体验者投入注意力、prosumer 投入创作劳动、组织者投入协调+情绪劳动、
  导师投入教学时间、批评者投入 voice。
- **平台须维持的条件**（conditions the platform sustains）：即五类结构障碍的
  反面——可进入性、基础设施稳定、关系性（受众/协作者在场）、规范秩序、治理回应。

这样「role-specific resources」不再需要作为术语存在（删），它变成一个陈述：
「各角色的主导资源不同，故各角色对条件失守的敏感点不同」。availability /
accessibility / direction / continuity 四词全部删除，其所指已被五条件覆盖。
闭环由此形成：**角色 × 资源 × 条件 → 价值；条件撤除 → 资源撤回 → attenuation**。
一条主线贯穿文献综述、发现、讨论，无一新词。

### 1.3 「repair-oriented voice」——您的疑问本身问对了：它不该在文献综述被「做成」

概念分工的一般规则：**文献综述埋张力，发现章节交付证据，讨论章节完成理论化**。
新概念的「形成」（正式命名、划界、与既有概念对话）属于讨论章节——溯因研究里
概念是分析的产出而非前提。文献综述只需一到两句张力铺垫：Hirschman 的 EVL 把
voice 当作 exit 的替代选项（由 loyalty 调节），既有平台研究把 voice 当作抱怨/
反馈行为；两者都没有把 voice 视为**共创性修复劳动**——投入者试图挽救其投资对象
的最后一种资源整合。

但更重要的建议是：**不要把 repair-oriented voice 立为第二个新概念**。反复被拒
的稿件最忌两个半成品概念。把它降格为 attenuation 的**子机制**：批评者阶段 =
投入者以 voice 尝试修复 → 修复失败（平台无回应）→ 资源彻底撤回。这样它作为
发现层面的描述性标签存在（可保留这个短语），理论化的重量全部压在 attenuation
一个概念上。若日后单独发展它，另写一篇。

### 1.4 「gap 清单而非理论谜题」+「文献综述重复引言」——确认，合并为同一病灶

两点是同一问题的两面：**引言和文献综述在做同一件事（罗列缺口），所以必然重复**。
现稿引言第四段的「three respects」结构（"say little about… have not been
examined… overlooks…"）就是典型 gap 清单——三个「还没人做过」不构成谜题，
「两个都被充分支持的理论预期相互矛盾」才构成谜题。

现成的谜题就在第二、三段，只是没有被写成谜题：
**共创理论预期参与深化带来价值累积（周边→中心）；证据却显示最深的参与者成为
最激烈的批评者与流失者。累积逻辑无法解释为什么恰恰是中心用户先崩溃。**
这一矛盾一句话立住，三个 gap 段落即可大幅删除。

分工规则（执行时按此删）：
- **引言**：现象 + 谜题 + RQ + 贡献预告，目标 ≤900 词。删去所有对 S-D logic、
  voice–exit 的展开性综述（SJM 版引言近 2000 词讨论理论，这些全部让位给文献综述）。
- **文献综述**：只保留分析要用的机制定义；每节结尾从「gap 句」改为「本研究分析
  所需句」（What the analysis therefore needs is…）；凡与引言重复陈述 gap 的
  句子整句删除。

## 二、我补充发现的问题（按重要性排序）

### 2.1 概念定位自相矛盾（前文已述，硬伤级）
2.4「distinct from co-destruction」 vs 讨论 5.2「antecedent to co-destruction」。
必须统一，建议删 antecedent 句。

### 2.2 层级滑移：ecosystem / community / structural property 的主张超出数据
2.4 称 attenuation 是 "structural property of the community"、"operates at the
level of the ecosystem"。10 次访谈 + 单平台公屏数据支撑不了 ecosystem 级主张。
删改方案：全文把 "ecosystem-level" 统一降为 "community-level"（单一 SVW 社区内
的模式），保留角色间依赖这一真正有数据的「结构性」内涵（见第四节）。

### 2.3 「recursive sequence」是分析排序，被写成了时间因果序列
发现 5.3 与讨论把五障碍写成「递归序列，每一层削弱下一层的条件」（入口→基础设施→
关系→规范→治理）。这是编码后的分析性排列，不是数据能证明的时间顺序——横断面为主
的六个月田野无法证明「先有准入收窄、后有关系侵蚀」。审稿人必问「序列的时间证据
何在」。删改方案：把 "sequence"、"each weakening the next" 的强因果语言改为
"compounding / mutually reinforcing conditions"（复合、互强），保留「累积」
「无单一断点」的核心主张——这恰是 attenuation 区别于 co-destruction 的定义性
特征，且有数据支撑。

### 2.4 情境贡献被当作理论贡献
「把共创扩展到具身沉浸环境」是 context extension，审稿人默认不算贡献，除非说明
情境**改变了理论本身**。现稿其实有这个论证（引言第三段：沉浸放大投入强度→放大
转化的烈度）但没有把它接到贡献表述上。删改方案：不再作为独立贡献列出，并入主
贡献——「沉浸情境是让内生衰减机制变得可见/加剧的放大器」。

### 2.5 RQ1/RQ2 是分类学问题，撑不起「so what」
「有哪些活动」「有哪些角色」邀请审稿人问「分类本身贡献何在」。若不动 RQ 结构
（符合您最小修改的要求），至少在 RQ 引出段把三问统摄于一个总问题之下：
「共创价值如何被其自身的参与结构内生地侵蚀」——RQ1/RQ2 交代被侵蚀的对象与载体，
RQ3 交代侵蚀机制。一句话即可完成，不必改 RQ 本身。

### 2.6 SJM 版特有风险：voice–exit 作为第四套框架进场
若 SJM 版引言以 EVL 为主导框架之一（您的描述如此），则理论框架达到四套，
这正是「用理论描述现象」观感的直接来源。建议：S-D logic（资源整合）作为唯一
骨架贯穿全文；EVL 只在批评者/退出阶段作为局部对话对象出现（文献综述一小段 +
讨论一段），从引言删除。

### 2.7 术语一致性残留
- attenuation 在 2.4 被定义为 "user-side process"（与 platform decay 划界），
  但讨论中又是社区/生态属性——与 2.2 的层级滑移同源，统一为：
  「用户侧资源撤回过程，在社区层面累积显现」。
- 价值四分类标签、五角色命名、五障碍命名需全文逐字统一（仓库版已基本做到，
  SJM 版需按同一清单核对）。

## 三、数据支撑力评估：能撑起什么、撑不起什么

语料（据方法论 4.2–4.3）：90 小时沉浸式网志（单平台 Light World，1–6 月）、
110 张截图、457 条公屏聊天记录、8000 词田野日记、10 次半结构访谈（30–45 分钟，
含参与下降者与已退出者）；单人编码 + 导师组 peer debriefing；中文数据作者自译。

| 理论主张 | 支撑度 | 依据与缺口 |
|---|---|---|
| 四类活动 → 四类价值的映射（RQ1） | **强** | N/I 双源均有代表性证据（编码表 Table 1），网志对活动的在场观察是强证据 |
| 五角色的功能分工（RQ2） | **中强** | 各角色均有 N/I 证据；但 I03 同时承担 prosumer 与 mentor 两个角色的例证——须言明「角色是位置而非人，一人可占多位」，否则「五角色」有被质疑为过度切分的风险 |
| 角色轨迹（周边→中心→批评/退出） | **中** | 依赖回溯性自述（如 I03 "maybe I can try this too"），非纵向观察到的转变。可主张「参与者叙事中呈现的轨迹」，不可主张「追踪到的轨迹」 |
| 投入者→批评者转化（全文最关键的理论抓手） | **中** | I04、I05 的退出叙事 + N26 等公屏证据。回溯性但内在一致；**前提是 I04/I05 的访谈中确有早期深度贡献的自述**（需回原始访谈核实）。这是数据刚好够、且最值得压重量的主张 |
| 五类结构障碍的存在（RQ3 前半） | **强** | 公屏聊天（457 条）对抱怨、批评、退出宣告是自然发生的强证据，编码表 Table 3 各障碍均有多源例证 |
| 障碍的时间递进/递归序列 | **弱** | 分析性排序，非时间证据。**删强因果语言，改为复合/互强**（见 2.3） |
| attenuation 作为社区级结构属性 | **弱中** | 单平台、10 访谈；角色间依赖有参与者自证（"quality creators are quitting"→组织者动力流失），但属参与者归因。降级为「单一 SVW 社区内观察到的模式」 |
| repair-oriented voice | **中弱** | 有 voice-before-exit 证据（N13 诉求、I04 "report is no use"、投诉与建议无回应），但「修复取向」区别于「抱怨」需要用户**提出建设性方案**的证据密度支撑。够一个发现层描述标签，不够一个独立新概念 |

**总判定**：数据可以稳稳撑起——**单一平台内、由资源投入结构内生产生衰减的
mid-range 过程模型**，即 sensitising-concept 定位的 co-creation attenuation
+ 投入者→批评者转化这一核心子机制。数据撑不起——完整新构念主张、障碍间的时间
因果序列、生态系统层级论断、跨平台一般化、repair-oriented voice 独立成概念。

换算成比例：主贡献（内生衰减 + 转化机制）约可获得 70–80% 的证据支撑（缺口是
纵向性，用回溯叙事 + 局限声明补）；若坚持构念化/序列化/生态级表述，支撑度掉到
40% 以下且给审稿人送靶子。**结论：不是数据不够，是主张超配。把主张削到数据的
边界内，贡献反而立得住。**

待原始数据入库后可补做的决定性核查：每个二阶主题的独立信源数（几位受访者、
几条独立公屏记录支持），这是审稿人衡量饱和度的实际标准；以及 I04/I05 早期
贡献自述的存在性。

## 四、删改执行原则（对应作者的「只删不加」方针）

1. **术语收敛表**：availability / accessibility / direction / continuity /
   role-specific resources → 全部删除，由「用户资源 × 平台条件（=五障碍反面）」
   二元结构替代；ecosystem-level → community-level；antecedent of
   co-destruction 句 → 删。
2. **引言**：删理论展开（S-D logic、EVL 综述性内容），删「three respects」gap
   清单改写为一个矛盾式谜题；目标 ≤900 词。
3. **文献综述**：删所有与引言重复的 gap 陈述；每节结尾 gap 句改为「分析所需」句；
   EVL 压缩为批评者阶段的一小段张力铺垫。
4. **发现/讨论**：删 "recursive sequence / each weakening the next" 强因果语言；
   贡献从三条并列删并为一条主贡献（内生衰减）+ 两个支撑面。
5. **不动**：段落结构、RQ 文本、四价值/五角色/五障碍框架、数据呈现方式。
