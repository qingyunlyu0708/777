Presenter: **Qingyun Lyu** · Mentor: **Prof. Suprateek Sarker** · Portland 117 · 13:30–16:00

## 文件 / What's here
| File | 用途 |
|------|------|
| **`index.html`** | 演示文稿本体。双击用浏览器（Chrome/Edge/Safari）打开即可全屏放映。单文件、离线可用、图已内嵌。 |
| **`slides.pdf`** | PDF 版（15 页 16:9）。会场电脑没法开 HTML 时用它兜底。 |

## 放映操作 / Controls
- **`→` / 空格 / 点击右侧**：下一页 ·　**`←` / 点击左侧**：上一页
- **`S`**：调出/收起当前页的一句话演讲提示
- **`F`**：全屏 ·　数字 **`1`–`9`**：跳到对应页 ·　`Home`/`End`：首/末页
- 深色/浅色主题自动跟随系统；投影仪建议用浅色。

## 导出/重做成 PowerPoint
`slides.pdf` 可直接导入 Keynote 或作为 PPT 背景。若要在 PowerPoint 重建：配色见下，字体用 **Palatino Linotype（标题）+ Helvetica/微软雅黑（正文）**。
